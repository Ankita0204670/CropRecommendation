**Crop Recommendation System | Python, Django, SQLite, Machine Learning**
- Developed a web-based crop recommendation application using Django to suggest suitable crops based on soil and environmental parameters.
- Implemented a Random Forest Classification model using N, P, K, temperature, humidity, pH and rainfall as input features.
- Performed data preprocessing, model training and evaluation using the Kaggle Crop Recommendation dataset.
- Integrated the trained machine learning model into the Django application to generate crop predictions through a user-friendly interface.
